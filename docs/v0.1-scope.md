# Hancho 0.1 Scope

Hancho 0.1 is a walking skeleton.

It supplies these commands:

- `hancho init`
- `hancho doctor`
- `hancho run`
- `hancho runs`
- `hancho show`
- `hancho logs`

It runs one built-in workflow with a deterministic fake harness. It stores its workflow version, events, result, and artifacts in `./.hancho/`. A new command process can read the final state. The default test suite does not use a network or paid model.

Hancho 0.1 does not use tmux. It does not write GitHub or Beadwork. It does not merge, push, release, or deploy. It does not leave an unmanaged background process.
